# Pac-Man42
Pac-Man clone in Python, built with Arcade for the 42 curriculum: procedurally generated mazes, ghost AI, 10+ levels, JSON config, persistent highscores and a cheat mode. Playable on itch.io.

## Maze Generation

Mazes are generated by the **A-Maze-ing** package assigned by 42, made by
another group (`mazegenerator` 2.1.0, MIT License). It is not our code, so the
wheel is **not included** in this repository.

To install it, place `mazegenerator-2.1.0-py3-none-any.whl` at the repo root
and run `make install` (or `make install MAZEGEN=path/to/file.whl`).
